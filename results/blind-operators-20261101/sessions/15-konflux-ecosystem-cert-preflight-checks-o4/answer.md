No environment note exists here, so I had to guess the workspace binding. I assumed Konflux's usual `volumeClaimTemplate`, which means the recovery run starts with an empty `workspace`. The tasks that never ran and read source from it (the three `sast-*` checks, `push-dockerfile`, and `build-source-image` if enabled) need `clone-repository` and `prefetch-dependencies` to fill it again. `ecosystem-cert-preflight-checks` and the image-only scans just need the `build-image-index` image URL and digest. That image is already in the registry, so `init`, `build-container` and `build-image-index` can be reused. This is only safe if `revision` is a fixed commit SHA: a branch could clone newer code than was built, and then all of `clone-repository` through `build-image-index` must rerun.
